# Security

## Scope

This repository contains cross-site scripting (XSS) test payloads, a testing
checklist, and a scanning helper script. It is intended for use only against
targets you own or are explicitly authorized to test. Running `Quantum-XSS`
against a system without permission may be illegal in your jurisdiction.

## Reporting an issue with this project

If you find a bug in `XSS.sh`, a mistake in the checklist, or an unsafe
default in this repository (as opposed to a vulnerability in a third-party
site you tested), please open an issue on GitHub.

This project does not process vulnerability reports for other people's
websites. If your testing with these payloads surfaces a real vulnerability
in someone else's system, report it to that system's own security contact.
